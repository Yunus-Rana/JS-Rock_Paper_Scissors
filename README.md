# Rock Paper Scissors

A simple, responsive Rock Paper Scissors game that you can play in your browser. Choose a move and compete against the computer; the scoreboard tracks wins for the current page session.

## Features

- Play Rock, Paper, or Scissors against a randomly selected computer move.
- See both moves and the round result after each turn.
- Track player and computer scores as you play.
- Responsive layout with interactive choice buttons.
- Built with vanilla HTML, CSS, and JavaScript—no dependencies or build step.

## How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer randomly chooses its move.
3. The winner of the round gets one point; ties do not change the score.

The standard rules apply: rock beats scissors, scissors beats paper, and paper beats rock.

## Run Locally

No installation is required. Clone or download this repository, then open `index.html` in a web browser.

Alternatively, serve the project with any static file server and open its local URL.
